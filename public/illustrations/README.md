# InspiredLearning original illustrations

Created for the 2.2.0 public landing page on 30 October 2026 with the built-in `image_gen` tool. Both images were generated as new assets with genuine transparent backgrounds; no reference identity or participant data was used. The selected outputs are stored here as WebP, optimized using cwebp quality 86 with alpha preserved. Original generated PNGs are retained outside the source tree. These are original project illustrations, not externally sourced stock assets.

- `learning-world.webp`: hero, 1280 × 1280; eagerly loaded with explicit dimensions.
- `learning-companion.webp`: community support image, 1280 × 1280; lazy loaded. Render dimensions reserve a square slot.

## Final hero prompt

Use case: illustration-story. Asset type: original illustration for InspiredLearning's learning-platform homepage. Create a charming, sophisticated cartoon scene of three young adult learners collaborating around an oversized open book that becomes a playful little landscape: stepping-stone pages, a friendly tiny notebook creature, a small laptop and a blooming idea plant. Warm inclusive Indian college community, varied skin tones, casual modern clothes, expressive simple faces. Flat editorial cut-paper cartoon with rounded organic shapes, subtle printed-paper texture, crisp silhouettes, modern Material 3 expressive sensibility. Palette anchored in soft violet, lavender, cream, with warm peach and muted teal accents; dark ink details. Composition: one cohesive square-ish island scene, all subjects fully inside image with generous transparent padding, works on both light and dark UI backgrounds. No rectangular backdrop, no shadows extending beyond composition, no words, no lettering, no numerals, no logos, no watermarks, no interface screenshot. This is a distinctive friendly brand illustration, not generic corporate clipart.
